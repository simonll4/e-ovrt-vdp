# El informe

*Plataforma experimental de detección open-vocabulary en video en tiempo real para monitoreo
asistivo de riesgos en construcción*

Proyecto Integrador · Ingeniería en Informática · IUA Córdoba, Facultad de Ingeniería · 2026<br>
Matías Lautaro Carrizo · Gabriel Agustín Guillaumet · Simon Llamosas — Tutor: Mariano García Mattio

**Archivo:** `E-OVRT-VDP-informe.pdf`, que se incorpora a esta carpeta con la versión
entregada.

Este repositorio es el complemento del informe: lo que el informe describe, acá se ve
—figuras, capturas, resultados con su fuente— y se puede seguir hasta el código. Cuando una
cifra de este repositorio y una del informe se citan juntas, manda el informe (sección y
tabla).
